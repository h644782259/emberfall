# 城镇旅行与 NPC 服务

- 风语营地默认开放；赤岩驿站角色 5 级开放；星望城角色 12 级或首次通关开放。旧存档缺失字段会迁移到风语营地，已解锁城镇保留，越界或未解锁的当前位置回退到城镇 0。
- 点击小地图或桌面右下「城镇旅行地图」，手机还可以从暂停菜单打开。地图显示三个城镇、解锁条件、当前位置与旅行状态。旅行免费；装备、物品 ID、药剂、货币及角色存档 ID 均保留，不重新生成背包。
- 挑战内、死亡、附近有敌人或场景切换时禁止旅行。只有旅行成功后关闭地图；失败保留地图并显示错误，返回/取消不写存档。从暂停打开后取消会回到暂停。
- 各城镇商人、铁匠、兑换员在相同服务坐标。靠近后出现明确交互按钮；移动端左侧交互按钮切换为「商人交易」「铁匠强化」「装备兑换」。小地图用金色点标出 NPC。
- 商人复用现有背包出售和药剂购买；铁匠打开现有部位强化并选中当前武器；兑换员打开工坊机制装备兑换页。三个城镇没有随机商店或价格差异。

## 交易安全

单件出售、购买药剂、批量出售均构建候选角色快照，磁盘写入成功后才公布内存变更、通知 UI 或报告成功。磁盘错误保留原金币、药剂、物品、主文件及备份；可以重试。

单件出售继续保护穿戴及锁定装备；批量出售额外保护机制、强化、史诗及以上装备。金币采用非负饱和上限 999,999,999，药剂上限 99；不足金币不扣费。重复出售同一稳定物品 ID 不会重复发钱，重复空批量不写磁盘。

## 验证边界

`Tests/HubTravelEconomyTests.cs` 对生产规则和真实服务执行确定性测试及唯一临时目录存档夹具，覆盖旧字段迁移、读取不写入、解锁边界、无效位置回退、锁定旅行、保存失败、财物保留、交易失败与重试、重复出售、装备保护和数量上限。`Tests/HubTravelSourceTests.py` 检查 UI、场景和原子交易的关键接线。

测试仅使用临时假存档，不使用任何用户存档。源代码/API 编译不等同 Unity 实机运行、画面或触屏体验验证。
