# 第二轮：战斗预算与成长衔接

## P0：数值与预警

- 装备强化改为每阶基础值 +5%、+10 合计 +50%；小属性保留每阶最低增量。所有计算都来自未强化基础值，避免换装/读档重复放大
- 旧强化存档迁移基础属性，保留物品身份、品质、锁定、最高部位强化等级和已投入资源；迁移后可见属性会降低，这是本次数值校准的明确变化。旧上限/不可逆舍入值采取保守反推，迁移结果重复存取不再改变
- 护甲换算尺度为 50 + 4×角色等级，护甲本身最多减伤70%，护甲与技能叠加最多84%。真正的闪避无敌帧不受此下限影响；风险契约在最后增加承伤
- 副本敌人等级不再与阶数重复相加；等级封顶后，阶数仍独立提高生命与伤害。界面展示两项倍率，现场人数上限不变
- 震地对圈内玩家与所有存活伙伴分别检查位置与地面阻挡；普通单体攻击仍可由伙伴承受。伙伴范围攻击承伤55%，召回期间再乘50%
- 距离决定可行招式，近期招式决定变化；远距弹幕后主动接近，冲锋落空有2.1秒追击窗口并取消立即追击连招。预警仍固定在本次动作锁定位置

## P1：成长选择与职业循环

### 精通

50/65/80/95级分别开放每方向10/20/30/35点。攻击、生命、护甲、技巧共140点容量，与原技能共用总共99个升级点；学满十技能后仍只有69点可投精通。旧三方向点满存档一次性全额返还精通点，避免替玩家选择新方案。

20点解锁方向核心，营地只能启用一个：

- 破敌：完美闪避后3秒内下一次普攻有效命中附加50%攻击伤害
- 生命：完美闪避恢复5%最大生命
- 坚壁：完美闪避后3秒获得25%减伤
- 技巧：完美闪避让全部技能剩余冷却减少1秒

核心奖励不叠层。营地免费重置精通/切换核心；失败写入不消耗点数。

### 元素师的两套完整打法

- 碎冰：同目标三次普攻积霜，未学新星保留微冻结、学后升级为霜痕；新星提供主要硬控；陨星在本次施法对该目标第一次真正满足冰霜条件时触发反应。护盾脉冲维持霜痕窗口；终极先积霜，最后一击引爆。霜回护符选择集中的伤害回响或更宽的低伤回响
- 灼燃：三次普攻触发余烬，新星减速留人，陨星铺火与灼烧；防御技能改为30%减伤、20%移速和移动途径火区；终极降低直伤并刷新灼烧。余烬法杖可选正常覆盖或半径缩小30%的集中高伤火区
- 每目标每施法的碎冰机会只在真实触发时消耗；先空陨星、后补新星、再命中的连携有效

### 伙伴与机制装备

- 常驻基础灵狼保留并随已学契约成长。契约键命令存活伙伴，死亡后可重新召唤；双契路线提供永久狼/星灵与限时树灵，群契路线保留基础狼并召集受上限约束的限时兽群
- 伙伴跨合法区域传送保留血量比例，清除旧目标/指令/连携；旧弹道与限时伙伴仍按战斗代数失效。不会用区域切换复活已死伙伴
- 双契装备普通伙伴上限2，伤害+60%、生命+20%；需要不同类型伙伴在1.5秒内实际命中同一集火目标才能共鸣，冷却3秒。星灵发射时不计数，真正命中才计数
- 回刃普攻代价从15%减到8%，每1.5秒对另一目标追加110%攻击；回收强化下一刀，击杀后再弹一次65%。新回收奖励不会被当前攻击末尾清掉
- 完美闪避提示实际回复的能量。满能量仍有职业奖励：剑卫反击、元素霜痕/余烬、游侠精准箭与短标记、唤灵师召回及强化下一次契约指令

### 暴击

普攻独立掷骰，直接技能一次施法使用同一个暴击结果，延迟命中保留结果。高级多段技能归一化为旧系数的24%，保留真实暴击标记。持续区域、灼烧、毒素、反应、装备附伤与伙伴不暴击；持续区域会同时移除暴击倍率和标记，避免只改显示。伙伴继承当前角色攻击/生命及契约阶数，生命上限变化保持比例而不免费治疗。技能说明及暴击提示列出规则。

## P2：长期目标

- 机制装备首次获得登记配方；已穿戴核心可用6碎片成长到当前等级，保留物品身份/机制/锁定和部位强化，避免每次12碎片重复兑换
- 元素机制装备4碎片解锁互斥变体，之后营地免费切换；同一个物品不会同时使用两种变体
- 祝福三选一优先从当前可生效候选抽取，至少两个立即适用，可能时三个都适用；未改动已选祝福不重复及每波一次规则
- 每次开箱+1星纹，重复时装额外+1/2/4/8，原金币补偿保留。30星纹可指定缺少的传说部位；重复选择已拥有部位不扣资源
- 时装属性使用各部位最高已收藏品质，外观自由穿戴或隐藏。稀有外观不会迫使玩家放弃已培养属性。星纹、收据、变体和重铸都通过先保存后发布结果的事务路径

## 玩法检查

在可运行 Unity 的环境检查场景、界面与以下玩法；平台构建和设备性能另行验证：

1. 20/50/100级三种装备，低阶/匹配阶/冲阶，记录实际Boss时长、完整攻防轮数、每种攻击失误损血；按矩阵而非单点调参
2. 玩家/两伙伴分别在震地内外、隔墙、死亡、召回，核对每个受击对象；带伙伴仇恨时玩家完美闪避仍能正常判定
3. 第一颗陨星无冰、补新星、第二颗命中；同施法不重复反应，不同施法仍可连携
4. 常驻伙伴学技能前后、死亡重召、双契/群契切换、满数量、跨区域、旧弹道失效；不同伙伴打不同目标不共鸣
5. 完美闪避在满能量/低能量、奖励过期/连续闪避；回刃当前攻击不能吃掉新获得的下一刀奖励
6. 营地四精通/两种元素路线/装备变体和时装选择在窄屏与触屏上的布局、点击和反馈；检查开箱展示、拾取记录和暂停行为
