# 危险边界、遮挡与低特效

第一批源码修改：敌方外边界始终橙红，独立橙红弧显示蓄力，青色短符号表示控制技能可打断。技能与首领教学对应此含义。

地面预览和释放标记共用 `CombatSight.FillAreaBoundary`。释放标记缓存静止轮廓，移动或 `WorldTraversal.Revision` 改变时重算。冰晶、火舌按整个世界空间包围盒的水平外接圆检查实体扫掠；近墙时保守隐藏整个构件，不仅检查中心。场域火舌/毒泡检查占地，区域粒子在 LateUpdate 删除被实体遮挡的粒子。水仍遵循法术可跨水规则。

装饰粒子最多24组（低档10），闪电最多16组（低档5），死亡余烬最多8组；粒子单组22–90粒、余烬低档2/4个，闪电低档4折点。隐藏时立即幂等归还，重新显示须重新申请。边界与计时/打断符号不消耗装饰额度。尸体死亡本体与伤害判定不依赖装饰成功。

验证：新增装饰租约纯逻辑测试，扩展生产遮挡几何测试，新增预警/效果源码接线契约；参考API编译仅证明源码可编译。尚无Unity实时渲染、镜头遮挡、触控尺寸或性能验收；保守隐藏可能让贴墙视觉偏稀疏，需要真实画面复核。
