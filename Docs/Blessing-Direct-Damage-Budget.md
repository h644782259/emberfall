# 祝福 B：固定直伤预算与倍率路径

本批将战意昂扬从 15% 改为 10%，鹰眼星辉从 +10 个百分点改为 +20 个百分点，致命锋芒从 195% 改为 215%；基础暴击倍率仍为 165%。鹰眼保留原 80% 祝福上限与“不降低已有更高暴击率”的规则。

固定基础暴击率 10%，固定等距随机样本，无护甲、移动、目标空窗、施法节奏与击杀时间假设：

| 组合 | 相对无卡的玩家可暴击直伤期望增幅 |
| --- | ---: |
| 鹰眼 | 12.21% |
| 致命锋芒 | 4.69% |
| 鹰眼 + 致命锋芒 | 26.29% |
| 战意 | 10.00% |
| 战意 + 鹰眼 | 23.43% |

基准期望为 `1 + 0.1 × (1.65 - 1) = 1.065`。表格是固定直伤预算，不是实战 DPS，也不是持续伤害、伙伴或整套连招的收益表。测试通过实际 PrepareRoomChoice/Choose 获取四职业的单卡和双卡组合，没有反射写入 active 集合。

路径审计：玩家 `CombatAttack` 乘一次本局攻击系数，`Damage/RollDirectDamage` 仅在可暴击直伤应用暴击概率与倍率，不重复攻击系数。持续伤害快照来自既有施法路径；燃烧/中毒 tick 消费存储伤害，不重新应用本局攻击系数或暴击。后续燃烧 F 属于独立批次，不能据此声称其整条运行时已模拟通过。

伙伴契约与属性刷新仍保存不含战意的 `stats.Damage` 基础伤害，普通攻击和狼指令在 `AttackMultiplier` 乘一次 owner 当前本局攻击系数；共鸣独立输出路径也乘一次。命令增幅、双契装备增幅仍按各自原有规则组合；免费集火不把增幅写回伙伴基础伤害，不增加暴击。离开副本由 owner 的本局门禁返回 1。

`Tests/BlessingDamageProductionTests.py <dotnet>` 执行真实 RunChoices/CombatDamage、实际 Player Damage/RollDirectDamage、伙伴 Command/OnConfirmedHit，检查一层倍率与运行范围，并执行缺失伙伴系数的编译后负对照。普通伙伴出伤以生产 AttackMultiplier 属性与基础伤害快照验证，未运行 Unity 伙伴移动/攻击 Update。持续 tick 的边界为源码接线约束，调度行为由原持续伤害测试负责。Unity 图形与设备实战未验证。
