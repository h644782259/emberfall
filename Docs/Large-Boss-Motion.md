# 星环首领阶段动作

蓄力时压低机体、收拢护片并撑住四肢；扫射时维持撑地姿态并露出定向发射口；暴露时完全展开护片、抬出核心、减慢星环；恢复时逐步收回核心并解除撑地。机体转向保留惯性，独立发射口使用与真实伤害束完全相同的 `BeamWorldAngle`，避免平滑转向使发射方向暗示错误。

星环角度由平滑角速度的解析积分推进，替代 `age * 当前速度`。切阶段只改变目标转速，不重算既有角度；停顿/终止不旋转，长帧最多推进0.1秒装饰动作。骨架/网格/材质沿用原有有界数量，仅增加一个发射口构件。

大型首领自己的扫射预警也保持橙红危险边界，青色符号独立表示可打断，蓄力弧独立计时。第二次机制开始即清零旧BeamAngle，避免第二次蓄力显示旧余角、释放才突然归零。

验证：45项原有及新增阶段规则断言、30,007项姿态/长期角度连续性/帧划分断言、原12项首领接线与新7项动画/真实束角度接线检查，完整runtime参考API编译。没有Unity实际帧、视频、性能测量或质感验收。
