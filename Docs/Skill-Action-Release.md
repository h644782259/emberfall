# 技能动作与真实释放

角色模型只提供动作和武器位置。PlayerController、SkillChargeController、技能序列、区域和投射物仍负责目标、资源与伤害。

## 准备、发力、出手、收势

普通主动技能接受输入后准备 0.14 秒，准备期间不产生伤害、不扣能量、不开始冷却。重复按键和切槽不会叠加释放。到达出手时重新校验资源、目标和落点，再执行一次原有施法事务。

已有蓄力技能保留原 0.4–1.1 秒准备时间，不叠加普通准备。暂停冻结准备；死亡、换场、换角色和明确取消会撤销未释放技能。施法使用输入时捕获的方向、目标和地面点。取消未释放准备不消耗技能预算。

| 职业 | 关键动作 |
| --- | --- |
| 剑卫 | 转腰挥剑、抬腿跺地、双手举剑下劈、持盾承力、前伸突刺和举手鼓舞 |
| 元素师 | 抬手投掷陨石、双手聚集风暴、持杖指向目标、撑杖施放漩涡 |
| 游侠 | 持弓、扣箭、拉弦、松弦、收弓；陷阱和毒蔓使用屈身放置动作 |
| 唤灵师 | 前推、撑地生长荆棘、抬手唤狼、指向炮台位置和下压召唤树灵 |

四职业第 3 槽是属性被动，不制造施法动作；第 8 槽保留真实防御触发，使用护身动作。出手帧先提交身体和武器姿态，再读取手/武器位置并创建实际技能。

## 持续技能与召唤物

持续技能按真实事件准备与发力。箭雨和陨石在飞行开始时出手，落地事件负责接触和伤害，不再次假装松弦。两拍之间回到准备姿势。

星灵炮台的炮筒有厚壁和开口。炮口位置随上部后坐姿态提交，弹体从真实炮口发出；炮膛至炮口的扫掠也要通过障碍检查。基座保持承重状态。

## 验证边界

生产测试验证实际动作变换、输入接受、释放事务、一次收费、暂停、取消和失效路径。Unity 原生工具使用隔离存档记录准备、出手和收势，检查真实武器位置与投射物生成点。截图、模拟器安装启动与设备性能验证分别记录，源码测试不代替视觉验收。
