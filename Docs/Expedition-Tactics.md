# 回廊远征：目标与路线差异

本轮修改现有五房远征，不新增第四试炼或另一套远征。Windows/iOS 同步源码；尚未发布游戏包。

## 审计与边界

此前前三房按固定次序使用布局 10/11/12，敌人以固定角度出生，类型按下标轮换，全部清怪才开门。随机编队 `EncounterPlan` 服务普通三波副本，没有改变这段循环。已有三试炼、休憩祝福、阶段首领、晶核事件和可破坏物继续复用。

这一轮只改变前三房的推进方式、护援协作和路线。休憩室与王座首领仍位于第四、第五房；普通三波、三试炼、结算阶数和奖励事务保留。没有新增存档字段，不保存半途远征，也不改变 iOS 导出、字体或 iPad 设置。

## 三种目标

| 目标 | 开门要求 | 推进取舍 |
| --- | --- | --- |
| 双印净化 | 依次站入两个半径 2.4m 的金色边界，各累计 3 秒 | 跨房转移；可先清场，或引开敌人争取站位窗口 |
| 截断供能 | 击败带金环的供能魔灵 | 优先切后排，或先处理挡路近战；无需击败全部护卫 |
| 北门突围 | 北部目标累计站位 4 秒 | 找路与拉怪后抢门；也可稳妥清场再开门 |

净化与突围中，3.8m 内视线相通的活敌人会暂停进度。离开、暂停或打开阻塞面板都不倒扣进度；单帧最多推进 0.25 秒，避免长帧跳过目标。没有限时失败或无限援军，清场后始终可以安全完成。目标完成后使用原有靠近北门交互，触屏不增加精确选点或新按钮。

前三房每房固定六名敌人：一名供能魔灵、两名守卫、两名哥布林、一名史莱姆。魔灵给 6m 内视线相通的同伴提供 30% 减伤，不保护自身或首领。金环标出供能者，青环标出当时受到护援的敌人；拉开距离、利用遮挡或击杀供能者都会解除护援。范围没有叠加机制。

提前开门后可以留下获取剩余敌人的正常击杀收益，也可以撤离；离场清理剩余敌人不会调用击杀或补发掉落。房间切换仍先完成存档，失败保留当前房间与冷却；成功后退役旧战斗和拾取回执。最终结算仍需完成王座房，沿用唯一收据。

## 地形与事件

前三房每局各使用一次中央遮挡、偏置桥、交错墙，另有左右镜像：

- 中央石墙分隔射线，形成两侧绕行；侧墙改变北部接近方向。
- 偏置桥使步行必须侧向过河，法术仍可越水，远近程受到不同限制。
- 交错横墙需要改变推进方向，并提供切断护援视线的拐角。

视觉墙体与导航从同一个 `TacticalRoomGeometry` 定义取值。目标与出口用真实导航检查步行可达，刷怪经过最多 48 次有界采样，距入口至少 5.5m、彼此至少 2.4m。生成失败明确结束远征而不发放结算，不伪造死亡推进。

复用晶核支线，种子决定它出现在前三房的哪一房，以及东西哪侧。目标完成后才可触发，仍是两名有限守卫换取原有碎片和补给；玩家可直接离开。主房六名加支线两名最多八名，不接入普通副本援军队列。首领房三名，锚点仍不计入敌人数。

## 种子与防重复

`RoomChainState(seed)` 可复现目标、地形、镜像和事件房；刷怪也只依赖种子、房间、下标和当前几何。日志记录调整后的实际种子，`GameSession.RoomRunSeed` 可供调试读取。共 54 种目标起序/地形起序/镜像/事件房组合；刷怪角度另有 97 档种子变化。这是规则组合数量，不代表 54 种已验证的试玩体验。

同一次 GameSession 内保存最近两次远征种子，约束连续三局开场目标与地形各不重复，包含放弃后再入场。该历史不写入角色存档，重启游戏后重置。没有承诺重启后防重复或玩家输入种子的 UI；复现从记录种子的构造器/调试入口进行。

## 验证与待验收

独立测试使用生产规则和导航代码；Unity 数学类型由现有 managed 测试替身提供。它们不运行 Unity 场景、敌人 AI 或触屏设备。

- `RoomChainStateTests`：540 个种子、54 种组合、1,000 次连续选择；目标推进、抢门、部分进度、暂停/争夺/非法时间、未生成/重复/过期死亡、失败与一次结算。
- `TacticalRoomGeometryTests`：六布局、三种导航半径，入口到两个目标/出口/支线的可达路径及每段合法性；种子化六人编队、实际候选选点、间距与入口净空。
- `RoomTacticsSourceTests.py`：暂停、护援视线、场景清理、存档前置与几何共用接线检查。
- 既有云端独立套件、Python 源码契约和 Unity API 参考程序集编译继续执行。两个 Editor 持久化/掉落验证夹具已适配净化开门前置，但本环境没有执行 Editor 验证。

发布前须在 Unity 中逐项确认：四职业对供能者的优先选中、净化边界与实际半径一致、敌人绕偏置桥和交错墙、护援提示在低特效下可辨识、开门留战/撤离、支线中途离场、菜单与后台暂停、存档失败保留世界，以及普通副本/三试炼/王座回归。iPhone 与 iPad 还需验证目标文本不遮挡触控、帧率、签名和安装。

没有 Unity 运行或真机证据时，不将路径/组合统计称作视觉、难度或手感验收。
