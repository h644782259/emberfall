# 人物技能实体主体与接触时序

本次覆盖四职业的共同实体特效入口。伤害仍由技能序列、投射物或区域 tick 结算，表现组件不选敌人、不扣血、不额外改变伤害预算。此文记录实现入口；原生截图、编译和模拟器证据见 ArtSource/Review/NaturalSkills-20261011/README.md，真机性能另行验证。

## 共同主体

- 剑士：真实带刃脊、护手与厚度的钢剑；地裂由厚断裂岩板和石屑组成。
- 元素师：冰晶、岩质陨石、火舌与自然放电；奥术晶体替代立方体框架。已确认的黑洞镜头遮罩保留。
- 游侠：真实箭头、箭杆与尾羽；落地箭头朝下嵌地，箭杆保留长度；毒蔓使用有木质细节的藤干。
- 唤灵师：完整灵兽身体替代契约图案与轨道管圈；召唤出场使用有惯性的飞行灵兽，召唤物本体仍由 SummonedCompanion 构建。
- 防护：胸甲、背甲、肩甲及侧甲替代保护笼。尺寸按人物身体固定，随人物旋转，状态结束由原防护通道立即取消。
- 风暴：不规则封闭尘团与受气流驱动的真实岩屑替代可见螺旋管线。

实体表面采用 HeroSkillBody，Filled、Performance 与 Blender 的材料入口通过 SkillBodyMaterialLibrary 绑定生成材质图集。岩石、金属、冰、木质根干、灵兽毛皮和湿泥分别选择对应材质。实体写入深度，仅在最后 .075 秒缩减覆盖率，避免持续出现大面积点状孔洞。脚下破裂、碎屑、接触装饰不显示几何作用范围。

普通落地钢剑的实际模型高度最多 2.405 米，终结技最多约 3.25 米；命中点位于施法者脚下时稍向前放置，让施法者保持可见。单次弧斩只使用一把宽厚钢剑，避免交叉剑形成星号。毒沼使用低矮湿泥和两至三株具有弯曲树皮体积的粗根，取消密集细藤与水晶刺尖。湿泥按源网格最大径向范围归一至真实半径的 .96 倍，泥体和根干都通过 AnchoredImpactMesh 保留掩体裁剪，持续阶段根干保持扎根姿态。

## 运动与实际效果一致性

`PrepareBeat(at, until, impactRadius)` 捕获当次真实释放点和目标地面，不追踪释放后移动的施法者。箭矢和陨石用共同 `PhysicalSkillMotion.BallisticPosition / BallisticVelocity`，垂直加速度为 9.81。until 来自实际事件剩余时间；过期事件传 0，直接隐藏飞行主体。

箭的运动基准是箭尖，而非箭杆根节点。旋转依速度切线，箭尖在真实伤害拍到达 SurfaceHeight(.04f) 上方 .025m；多箭各自采样地面，实际脉冲半径限制其分布。PrepareBeat 所在帧不再次累加 deltaTime，避免提前一帧落地。

`Beat()` 在真实伤害事件处退役飞行主体，接触由 ArrowBeat 或 Filled 的已插地/已破裂实体承接，避免在实际伤害后重新发射箭、缩短箭杆或假装迟到。

石屑使用共同 PhysicalSkillMotion.Advance：恒重力、带半径扫掠、实体地面高度、世界障碍、反弹损耗与摩擦。不会碰撞或推动人物、怪物，不产生伤害。灵兽与风暴岩屑存在持续施法力；灵兽用阻尼加速度转向，风暴用切向气流和向心恢复力，碎屑仍由共同地面/墙体机制约束。

## 验证与审核

- HeroBodyFlightProductionTests.py 执行实际 flight 方法：箭尖释放/落地、恒重力、窄高台、实际范围、施法者移动后的快照、过期事件隐藏和 Beat 退役；437 项检查通过，箭尖偏移、接触不退役、过期仍发射三个生产代码错误注入均被拒绝。此检查不代表引擎或 GPU 验收。
- 引擎审核仍需四职业 0–9 槽 × 一至三阶、降低特效和移动档。尤其检查天幕/万箭落地帧、陨石同拍结算、坡面箭尖、高台边缘、掩体旁地裂、治疗和防护结束、暂停/死亡/换场后的撤销。
- 旧测试把 ContractSigil、ProtectionCage、CrescentCore 或旧网格名称当作正确性要求。这些断言与本次有意替换冲突，应围绕实体体积、时序、掩体、资源寿命和状态取消更新，不应为了旧外形继续保留几何主体。
