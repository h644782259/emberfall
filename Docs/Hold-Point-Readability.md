# 守点圈与实际争夺

可见圈、玩家占领、敌人争夺共用 `ExpeditionModeState.HoldPointRadius = 3.2m`。敌人的实际导航占地圆与圈相交才产生争夺，取消旧的中心6米压力判定。击退出圈后继续计时，争夺/离圈保存既有进度；仍须同时满足本阶段全部击杀和占领时间。

`HoldState`提供Inactive/Outside/Contested/Capturing/Secured，手机挑战卡复用已验证的76高目标区域，显示真实状态与进度；远征四行目标卡不变。低特效不隐藏目标圈。

`HoldIdleWaitSeconds`是本局累计“阶段敌人全部击杀后、占领计时仍不足”的有效战斗时间；包括离圈返回与圈内剩余等待，暂停/死亡/终局不累计。最后一帧只累计实际剩余占领时间，不把大delta余量计入。该数据供录制/复核，不写角色存档。

验证：旧试炼状态7,765断言、新守点状态/身体触圈/暂停/击退/等待41断言、4项接线契约、参考API编译。尚未用Unity实际验证视认性、AI绕圈或触屏体验。
