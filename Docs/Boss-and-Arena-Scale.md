# 首领、树人与战斗场地尺寸

`BossScaleRules` 是模型尺寸、寻路半径、生成净空和飞弹身体胶囊的共同入口。普通首领在既有模型上扩大 **1.5 倍**，大型远征首领扩大 **1.45 倍**，召唤师技能 9 的树人扩大 **1.5 倍**。普通怪物和其余召唤物保留原尺寸。缩放施加在 `CombatModel` 上，战斗根对象保持单位缩放；供能锚与地面场景不会随首领根对象被二次缩放。

| 对象 | 寻路半径 | 飞弹命中半径 | 身体高度 |
| --- | ---: | ---: | ---: |
| 普通首领 | 1.35 | 1.575 | 5.70 |
| 大型远征首领 | 1.8125 | 1.885 | 6.38 |
| 终极树人 | 1.05 | 1.35 | 4.80 |

首领生成净空为对应寻路半径加 0.15。玩家飞弹对首领直接使用完整身体高度，避免旧 5 米上限裁掉扩大后的头部。树人的敌方飞弹接触也使用同一尺寸入口。碰撞是实际三维胶囊扫掠，不把高于身体的飞弹转成二维命中。

普通首领弹幕从模型中的 `Guardian ember crystal` 发射；大型首领使用 `Exposed star heart`。发射点读取实际动画 socket 高度。弹幕方向从该高度指向蓄力时记录的玩家身体或召唤物身体快照，保留纵向速度。移动速度随体型倍率增长，持续时间仍为 3 秒；预警距离读取相同三维速度的水平分量，避免扩大后的首领向玩家头顶平射或预警射程与弹幕不符。

震地半径、冲锋宽度、冲锋速度、冲锋距离、攻击判定和闪避判定一起乘体型倍率。首领招式选择的距离输入除以倍率，以保留近距震地、中距冲锋、远距弹幕的原有阶段关系。大型首领扫射的绘制、完整胶囊裁切与伤害使用同一扩大后的宽度；供能锚距核心按首领倍率扩大。技能伤害、生命、奖励、阶段时间和树人寿命不因尺寸改变。

只有实际配置包含首领的以下场地将 **XZ 扩大 1.25 倍**，Y 高度不变：

- Layout 0、1：沉星遗迹最终波。
- Layout 4：`BossGauntlet`，模式 2。
- Layout 14：回廊远征王座首领房。
- Layout 105：首章 `StarPlatform` 的首领房。

`HoldPoint` 和 `TimedBreakthrough` 的生产阶段配置没有首领，Layout 2、3 保持原尺寸。其余战术房与章节路径也保持原尺寸。遗迹场地可行走半径从 28 扩至 35，其余首领房从 18 扩至 22.5。导航固定网格覆盖 35 米半径；地形及 shader 使用同一实际半径。游戏镜头在扩大场地中额外拉远 15%。

场景构建期间 `WorldTraversal.BeginSceneBuild` 统一缩放注册中心、XZ 尺寸、河流、桥和跳台；`finally` 保证恢复单位倍率。遗迹既有嵌套 1.5 倍 cathedral 变换由真实父对象坐标换算，避免柱子模型与导航错位。有限实体物理边界来自真实 mesh 的世界顶点，不能再次乘场地倍率。门、入口、首领生成位置和章节目标采用同一 `ArenaSizeRules.Point`；已换算的章节点用 `LocalPoint` 回到几何父对象下，避免二次缩放。场景构建结束后的可破坏道具和运行时供能锚使用世界坐标。

薄表面支撑与导航障碍独立。`WorldBuilder.GroundSupport` 在最终 mesh 与旋转完成后记录地毯、营地石庭、道路、薄石板与桥面的真实向上三角面，并按 material 的 `TerrainFollow` 在查询点加地形高度一次。附近三角面使用空间桶查询。`SurfaceHeight`、碎屑的 `PhysicalSurfaceHeight`、地面移动、生成及闪现落点共用这些支撑面；它们不增加导航障碍或改变导航地图身份。贴地 mesh 在已注册跳台顶面上的 closed-fan 证书只略过实际低于 origin 和所有面顶点的该支撑跳台，低于侧面的面和其他遮挡物继续被裁切。

`Tests/BossArenaScaleProductionTests.py` 执行生产尺寸规则、阶段配置、实际寻路、章节计划、socket 瞄准、三维接触与完整扫射裁切，并包含编译负对照。`Tests/GroundSurfaceSupportProductionTests.py` 执行 `NaturalPavingSurface.Create` 的原始几何代码，生成实际营地石庭、地毯和旋转铺石，检查闭合体、磨损边缘的下落支撑高度、移动、碎屑、导航隔离与跳台顶面/侧面证书。引擎 double 仅存储 mesh 数值及变换；材质、场景光照和原生渲染另行验收。

原生验收需在真实 Main 场景使用隔离存档，检查实际首领模型和技能 9 的准备/释放、寻路、胶囊命中、socket 与场景注册。桌面 Unity 检查与 iOS/Windows 实机帧率及操作验收分别记录。

Unity 6000.6 的 `BakeMesh(...,true)` 会补偿 Renderer 的 Transform 缩放；换算世界坐标时只调用一次 `TransformPoint`。普通首领的连续袖/裤有蒙皮，逐顶点测量可对照 `bone.localToWorldMatrix * bindpose * sourceVertex` 的独立世界位置，避免用未补偿的 baked 顶点再次乘模型倍率。角色各实体应具有有限的非零三轴 source bounds 与有限法线；有效的平面地形 mesh 不使用角色体积断言。
