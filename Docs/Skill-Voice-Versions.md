# 技能语音版本

设置 → 声音与画面 → 技能语音，点击依次切换原版（虚构咒语）、粤语、English、普通话。默认原版，选择保存在本机 PlayerPrefs，与角色存档独立；切换停止旧吟唱并加载所选语言，下一次施法生效。原有施法声、打击声和背景音乐不变。

每种新增语言覆盖四个职业各八个主动技能，共 96 条离线 WAV。被动槽 3、8 不生成语音。技能语音仍沿用原来的单声道播放、静音/暂停/死亡中断和吟唱节流规则。资源缺失时回退原版。

使用 macOS 已安装的 Sinji（粤语）、Samantha（英语）、Tingting（普通话）系统合成音色。生成：

```sh
python3 Tools/Generate-LocalizedSkillChants.py
```

中文文案来自 GameTypes 中的技能名，英文文案在生成器中维护。新增语言复用原版 Generate-SkillSoundscapes.py 的静音裁切、职业变调比率（0.76、0.91、1.04、0.81）、饱和处理、五层短反射、淡入淡出及归一化参数；各职业语速保留战士较快、游侠最快的关系。底层 TTS 音色不同，处理参数一致不等于音色或韵律完全相同，最终听感需要试听验收。

Unity 批处理验证入口：`Emberfall.Editor.SkillVoiceValidation.Run`，检查 128 条原版及新增资源、四档选择、持久化和无效设置回退。
